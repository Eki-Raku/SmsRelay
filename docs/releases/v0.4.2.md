# 短信信使 0.4.2

这是短信信使的首个公开发布版本。它面向这样的个人场景：SIM 卡留在备用 Android 手机上，而你不在手机旁边时，仍能从邮箱看到新短信。

## 本版内容

- 新短信通过 QQ SMTP 自动投递到指定邮箱；发件邮箱和收件邮箱可以不同。
- 支持申请系统默认短信应用，以适配新版本 Android 对验证码短信的接收限制。
- 提供短信查看、发送、转发记录、失败重试和链路测试。
- 增加 5 步初始化引导，把短信角色、短信权限、通知权限和邮箱配置串在一起。
- 区分“不是默认短信应用”和“缺少读取短信权限”，避免误导用户。
- 支持后台常驻、开机自启、深色模式和大字体。

## 安装

1. 下载 `SmsRelay-0.4.2-release.apk`。
2. 核对同页 `SHA256SUMS` 中的 SHA-256。
3. 在你信任的备用机上允许浏览器或文件管理器“安装未知应用”，然后安装 APK。
4. 按首次启动引导授予默认短信角色和必要权限。
5. 配置 QQ 发件邮箱、SMTP 授权码与收件邮箱，保存后执行“测试邮件投递链路”。

从 `0.4.1` 可直接覆盖升级。首次升级到 `0.4.2` 会显示一次初始化引导；完成或跳过后不会重复出现。

## 风险提示

本项目未经独立安全审计，也未在任何应用商店上架。它会接触短信正文、验证码和 SMTP 授权码，请仅在你完全控制的备用机上用于个人、非商业场景。短信转发可能因断网、省电策略、厂商后台限制或邮箱故障而延迟或失败。
